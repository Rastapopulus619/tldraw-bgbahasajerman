WRAPPER ARCHITECTURE:
- AppContainer wraps both Sidebar and Tldraw as SIBLINGS
- Sidebar never unmounts when switching whiteboards
- State persists: scroll position, expanded folders, selection
- Only Tldraw canvas re-renders with new store

STORE MANAGEMENT:
- Each whiteboard has its own TLStore
- Created via createTLStore({})
- Loaded via loadSnapshot(store, snapshot)
- Passed to <Tldraw store={store} />
- Old store disposed when switching

AUTO-SAVE:
- Listens to editor.store.listen()
- 2000ms debounce (2 seconds)
- Saves to /api/whiteboards/save?id=...
- Includes color palette in metadata

COLOR PALETTE:
- Embedded in each board file as metadata.colorPalette
- 28 colors with light/dark values
- Prevents old boards from changing when palette updated

MAJOR ISSUES ENCOUNTERED & RESOLVED
================================================================================

ISSUE 1: Express 5 Wildcard Route Pattern
Problem: app.get('/api/whiteboards/:id') doesn't capture slashes
Impact: Nested paths like "folder/board.tldr" fail with 404
Solution: Changed to query parameters (?id=folder/board.tldr)

ISSUE 2: CORS Errors from Remote Devices
Problem: Frontend hardcoded http://localhost:3001
Impact: Tailscale devices can't access API
Solution: Added Vite proxy, changed to relative URLs

ISSUE 3: CSS Variables Not Defined
Problem: Sidebar outside tldraw's theme context
Impact: White sidebar, no theme switching
Solution: Added fallback colors + @media queries, later switched to class-based (.theme-dark)

ISSUE 4: Theme Not Switching Automatically
Problem: @media only responds to system theme, not tldraw toggle
Impact: Clicking tldraw theme button doesn't update sidebar
Solution: Created TldrawWrapper with useIsDarkMode(), applied .theme-dark class

ISSUE 5: File Tree Not Refreshing
Problem: onRefresh callback not passed to FileTreeNode drag-drop
Impact: Operations succeed but UI doesn't update
Solution: Passed onRefresh prop through entire component tree

ISSUE 6: Keyboard Shortcuts Not Working (CRITICAL)
Problem: TWO listeners competing - both in capture phase
Impact: F2, Ctrl+C/V, Delete don't work
Solution: Removed FileTree listener, exposed operations via window.__sidebarFileOps

ISSUE 7: Folder Click Expands Instead of Selects
Problem: handleClick does both select AND expand
Impact: Can't select folder without expanding
Solution: Separated chevron onClick from folder onClick

USER WORKFLOW & FOCUS MANAGEMENT
================================================================================

TYPICAL WORKFLOW:
1. User opens sidebar (Ctrl+B or click expand)
2. Sidebar gets focus (blue border on right edge)
3. User performs file operations (rename, organize, etc.)
4. When sidebar focused: ALL keyboard input goes to sidebar ONLY
5. User shifts focus to whiteboard (click canvas or Ctrl+Shift+E)
6. Canvas gets focus (blue border disappears)
7. User edits whiteboard with full tldraw keyboard shortcuts
8. For long editing sessions, user closes sidebar (Ctrl+B)

FOCUS BEHAVIOR:
- Sidebar focused: Blue 3px border on right edge
- Canvas focused: No border
- Click anywhere switches focus
- Ctrl+Shift+E toggles focus

KEYBOARD ROUTING:
- When sidebar focused: Events blocked from tldraw (stopPropagation in capture phase)
- When canvas focused: Events reach tldraw normally
- Ctrl+B and Ctrl+Shift+E work globally (regardless of focus)

AUTO-SAVE IMPLEMENTATION:
```typescript
useEffect(() => {
  if (!editor) return
  
  const unsubscribe = editor.store.listen(() => {
    clearTimeout(saveTimeoutRef.current)
    saveTimeoutRef.current = setTimeout(async () => {
      const snapshot = editor.getSnapshot()
      await fetch(`/api/whiteboards/save?id=${encodeURIComponent(whiteboardId)}`, {
        method: 'POST',
        body: JSON.stringify({
          tldrawSnapshot: snapshot,
          metadata: { colorPalette, createdAt, lastModified, boardName }
        })
      })
    }, 2000) // 2 second debounce
  })
  
  return () => unsubscribe()
}, [editor, whiteboardId])
```

KEYBOARD SHORTCUTS CENTRALIZATION:
```typescript
// useKeyboardShortcuts.ts
window.addEventListener('keydown', (e) => {
  // Global shortcuts first
  if (ctrlOrCmd && e.key === 'b') { toggleSidebar(); return }
  
  // Sidebar-specific shortcuts
  if (sidebarActive) {
    const ops = window.__sidebarFileOps
    if (e.key === 'F2') { ops.startRename(); return }
    if (e.key === 'Delete') { ops.deleteSelected(); return }
    // etc.
    
    // Block ALL other keys from tldraw
    e.stopPropagation()
  }
}, true) // Capture phase!
```

SMART PASTE DESTINATION LOGIC:
```typescript
const selectedNode = findNode(nodes, selectedFileId)

if (!selectedNode) {
  destinationPath = '' // Root
} else if (selectedNode.type === 'folder') {
  destinationPath = selectedNode.path // Into folder
} else {
  // Into file's parent
  const parts = selectedNode.path.split('/')
  parts.pop()
  destinationPath = parts.join('/') || ''
}
```

FILE TREE SORTING ALGORITHM:
```typescript
nodes.sort((a, b) => {
  // 1. Pin welcome.tldr to absolute top
  if (a.name === 'welcome.tldr' && a.type === 'file') return -1
  if (b.name === 'welcome.tldr' && b.type === 'file') return 1
  
  // 2. Folders before files
  if (a.type !== b.type) {
    return a.type === 'folder' ? -1 : 1
  }
  
  // 3. Alphabetical within same type
  return a.name.localeCompare(b.name)
})
```
